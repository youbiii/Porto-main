# 🌐 Personal Portfolio Website

A modern, responsive, and interactive personal portfolio showcasing my software engineering projects, technical skills, and experience. Built with performance and fluid user experience in mind.

---

## ✨ Features

- **Responsive Design:** Fully optimized for seamless viewing across mobile, tablet, and desktop devices.
- **Smooth Scrolling:** Integrated with Lenis for an effortless browsing experience.
- **Fluid Animations:** Micro-interactions and transition effects powered by Motion (Framer Motion).
- **Clean Architecture:** Modular component structure built with React and Vite for fast load times.
- **Modern UI:** Minimalist and accessible interface styled with Tailwind CSS and Lucide icons.
